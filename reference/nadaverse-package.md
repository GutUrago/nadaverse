# nadaverse: Browse Microdata Catalogs Using 'NADA' REST API

Provides a unified, programmatic interface for searching, browsing, and
retrieving metadata from data repositories that use the National Data
Archive ('NADA') software, such as the World Bank, 'FAO', the
International Household Survey Network ('IHSN'), 'UNHCR', the World
Health Organization, and the statistics offices of Kenya and Zambia.
Functions discover available data collections, country codes, and access
types, search by keyword, country, and year, and retrieve study
metadata, file lists, and variable-level data dictionaries.

## Details

Start with
[`catalogs`](https://guturago.github.io/nadaverse/reference/catalogs.md)
to see the supported catalogs, then use
[`search_catalog`](https://guturago.github.io/nadaverse/reference/search_catalog.md)
to find studies. Use
[`metadata`](https://guturago.github.io/nadaverse/reference/catalogs.md),
[`data_files`](https://guturago.github.io/nadaverse/reference/data_files.md)
and
[`data_dictionary`](https://guturago.github.io/nadaverse/reference/data_files.md)
to inspect a study.
[`set_user_agent`](https://guturago.github.io/nadaverse/reference/set_user_agent.md)
changes the user agent sent with requests.
